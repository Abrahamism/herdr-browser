Chromium (web browser)

From Wikipedia, the free encyclopedia

Chromium is a free and open-source web browser project, mainly developed and maintained by Google. It is the base for browsers such as Brave, Microsoft Edge and Opera.

Agent control

This window was opened by herdr-browser on its own dedicated profile, with a DevTools endpoint on 127.0.0.1. The agent clicks, types and scrolls inside the page; the pointer you are using stays where it was, in the other window.

Every open tab is a target on that endpoint, which is what the panel in Herdr reads every three seconds. Picking one there brings that tab forward here.

Extensions

Unpacked extensions load from a directory, so the browser keeps the tools you already use, and the profile is its own: importing the cookies from your everyday browser is one explicit command, not something this does on its own.

Chromium (web browser)

From Wikipedia, the free encyclopedia

Chromium is a free and open-source web browser project, mainly developed and maintained by Google. It is the base for browsers such as Brave, Microsoft Edge and Opera.

The browser is driven through the Chrome DevTools Protocol: the agent clicks, types and scrolls inside the page, while the pointer you are using stays exactly where it was.

Every open tab is a target on that endpoint, which is what this panel reads.

Agent control

The browser is driven through the Chrome DevTools Protocol: the agent clicks, types and scrolls inside the page. The panel asks 127.0.0.1:64659/json/list for the target list every three seconds, so a tab that opens or closes shows up on its own.
